# Changelog

All notable changes to this project are documented here. Versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0-alpha] — 2026-10-23

### Added
- Playable vertical slice: full shift loop (customers → orders → crew → pickup → payment) and between-day management.
- Donut production line with batch frying, glazing, display case par levels, and a player-controlled fry timing minigame.
- Coffee bar and cold bar with 8 drinks, flavour shots and skill-gated recipes.
- Behaviour-tree crew AI: task scoring, breaks, assists, cleaning, focus stations, mistakes, XP and level-ups.
- Six customer types including food critics and influencers (viral boosts).
- Nine random events: snow day, holiday rush, school opening, championship night, breakdowns, power outage, health inspection, sick day, viral post.
- Economy ledger, live dashboard graphs, end-of-day summary, career ranks Trainee → CEO.
- Six store locations with distinct traffic, prices, rent and customer mix; passive income from owned stores.
- Save slots, autosave, schema migration, optional cloud mirror / HTTP provider.
- JSON modding with merge-by-id, plus an example mod.
- Procedurally generated SFX, ambience and music.
- Unit tests (267 assertions), headless 3-day gameplay simulation, GitHub Actions exports and releases.
