# Roadmap

## v0.1 Alpha — vertical slice ✅ (this release)
- One fully playable store with six unlockable locations and passive income from owned stores
- Donut line (mix → fry → glaze → case) with fryer timing minigame
- 8 made-to-order drinks across coffee bar and cold bar
- 6 customer types with patience, mood, loyalty, favourites, critics and influencers
- Autonomous crew on a behaviour tree: stats, personalities, stress, breaks, mistakes, XP, teamwork assists, focus stations
- 13 tracked ingredients with shortages, rush deliveries and Smart Inventory auto-restock
- Day/night cycle with four rush periods and nine random events
- Economy ledger, live dashboard graphs, end-of-day summary
- Career mode Trainee → CEO
- Save slots + autosave with schema migration, optional cloud mirror/HTTP
- JSON modding
- Procedural audio, responsive UI, keyboard/mouse/touch/gamepad
- CI: unit tests, gameplay simulation, Linux/Windows/Web/Android exports, tagged releases

## v0.5 Beta
- Drive-thru lane with its own queue and timer
- Delivery orders (third-party app tickets with pickup windows)
- Sprite art pass (replace procedural drawings with an atlas; keep procedural as fallback)
- Employee personalities with relationships (friends work faster together, rivals argue)
- Dynamic weather visuals tied to events
- Localisation (EN, ES, HI to start)
- Steam achievements via GodotSteam; Google Play Games achievements on Android
- Balance pass from playtest telemetry

## v1.0 Release
- Online leaderboards (daily profit, best rating)
- Franchise mode: set policies for stores you don't actively manage
- Stock market / business mode for the CEO tier
- In-game mod browser (Steam Workshop on PC)
- Local co-op (two managers, split responsibilities)
- Store front-of-house customisation (tables, décor, music)
- Store page assets, trailer, iOS TestFlight
